# Clics Rapides

Jeu simple où le joueur doit cliquer le plus de fois possible sur un bouton en 10 secondes.

## Installation

1. Cloner le dépôt.
2. Installer les dépendances :  
npm install

3. Lancer le serveur Node.js :  
npm start

4. Ouvrir dans un navigateur :  
http://localhost:3000


## Déploiement

Ce projet peut être déployé sur une plateforme supportant Node.js (comme Render, Heroku, etc.).

- Le serveur Express sert les fichiers statiques du jeu.
- Le port est configurable via la variable d'environnement `PORT`.
