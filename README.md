# Clics Rapides

Jeu simple où le joueur doit cliquer le plus de fois possible sur un bouton en 10 secondes.

## Installation

1. Cloner le dépôt.
2. Installer les dépendances :  
npm install

3. Lancer le serveur local :  
npm start

4. Ouvrir dans un navigateur :  
http://localhost:3000


## Déploiement

Ce projet peut être déployé sur n'importe quelle plateforme supportant des sites statiques, comme Render, Netlify, Vercel, etc.
